About the voice

Your Mac's voice — not a private Siri API.

Sorrel uses macOS system speech. If you choose a Siri voice in System Settings > Accessibility > Spoken Content and macOS makes it available to system speech, Sorrel follows that setting. It never uses a private Apple API — just the voices your Mac already offers.

FAQ

Good questions.

Does Sorrel monitor my clipboard?

No. It reads the clipboard only when you paste, click Replace & Play, press the optional hotkey, or invoke a command — never in the background.

Does my text leave my Mac?

Not for System Voice playback — everything stays on-device. Only if you opt into a cloud voice does the filtered text get sent to that provider over HTTPS, using your own key.

Do I need to be online?

You need internet to download Sorrel, buy a license, receive or recover a key, or use optional cloud voices. After activation, System Voice playback and license verification work offline.

Do I need an API key?

No. API keys are only for the optional advanced cloud voices. The built-in System Voices need nothing.

How do I use a Siri voice?

Open System Settings > Accessibility > Read & Speak (Spoken Content on older macOS), open System Voice, choose any voice named Siri, and wait for it to finish downloading. If Siri is not listed, click the ⓘ next to System Voice to download one first.

What do I need to run it?

A Mac running macOS 14 (Sonoma) or later. Sorrel ships as a signed and notarized macOS build, so it opens cleanly.
